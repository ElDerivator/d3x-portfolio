How it works — detalles técnicos
RowGuid portable
Identidad = row id de Dataverse; las relaciones no se re-key en la migración.
BusinessKey
Clave humana única (SUB-000384, CO-017, NCR-000045) = alternate key.
Human Gate
Reported → Verified → Official. La acreditación la produce solo el Flow, no la app.
OfficialProgress append-only
Cada acreditación es una fila inmutable; el "vigente" es una proyección, nunca un update.
Evidencia
Archivos en una Library; la relación autoritativa vive en metadata portable (record_guid).
Snapshots inmutables
Foto as-of por corte; bi-temporal (valid-time + knowledge-time). Nunca se recomputa.
Change orders
No reescriben baseline ni historia: alcance vigente = baseline + Σ deltas aprobados.
Migración Dataverse
V1 diseñada portable (GUID + BusinessKey + choices catálogo) para migrar sin re-key.

Todos los valores son demo (EL-00452, Colo 2B). Sin correos, tenant IDs, tokens, app IDs, GUIDs reales ni URLs internas.
